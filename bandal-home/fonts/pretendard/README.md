Pretendard Variable 1.3.9 dynamic subset, copied unchanged from the
`pretendard` npm package (`dist/web/variable/`). Copyright (c) 2021 Kil
Hyung-jin, licensed under the SIL Open Font License 1.1 (`LICENSE.txt`).

This is the same subset the LabVium web build bundles in
`frontend/demo/fonts/pretendard/`. The BANDAL homepage serves it from
`/fonts/pretendard/`. Browsers download just the `unicode-range` subsets a page
uses; the system font stack remains the fallback while they load
(`font-display: swap`).
