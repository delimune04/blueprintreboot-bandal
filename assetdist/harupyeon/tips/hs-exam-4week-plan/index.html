시험이 한 달쯤 남았을 때 ‘이번에는 세 번씩 읽어야지’라고만 정하면, 무엇을 얼마나 준비해야 하는지 끝까지 모를 수 있어요. 과목별 시험 범위와 자료를 모으고, 아직 설명하거나 풀지 못하는 부분을 찾은 뒤, 시험일까지 여러 번 확인할 시간을 나눠 보세요.

아래 4주 계획은 시작을 돕기 위한 가상 예시예요. 모든 학생에게 필요한 공부량이나 성적을 보장하는 공식은 아니에요. 학교가 안내한 시험 일정·범위·평가 방법과 현재 이해 상태에 맞게 바꾸면 돼요. 특정 학원이나 교재가 항상 낫거나 못하다고 정하는 글도 아니에요. 먼저 내 시험에서 확인해야 할 내용을 알아야 다른 자료도 필요한 만큼 고를 수 있어요.

1. ‘이번 시험’의 날짜와 범위를 먼저 맞춰요

학교 시험 공지와 과목별 안내에서 시험 날짜, 과목 순서, 범위, 문제 형식, 준비물을 확인해요. 친구의 메모나 작년 시험지를 보더라도 올해 안내와 같다고 가정하지 마세요. 시험 범위가 아직 확정되지 않았다면 지금까지 배운 부분과 예상되는 부분을 ‘확인됨 / 잠정 / 질문 필요’로 구분해요.

교과서, 학교가 지정한 부교재, 수업 중 받은 자료, 필기, 공개된 연습문제를 한곳에 모아요. 부교재는 교과서 외에 수업에서 함께 사용하는 책이나 자료예요. 자료마다 교과목과 단원, 해당 쪽이나 프린트 번호를 적으면 나중에 같은 내용을 다시 찾기 쉬워요. 프린트가 빠졌다면 수업의 공식 자료실이나 선생님이 허용한 방법으로 확인하세요.

‘학교 자료부터’라는 말은 프린트의 문장만 외우면 시험이 그대로 나온다는 뜻이 아니에요. 수업에서 배운 개념과 학교가 안내한 범위를 찾기 위한 출발점이라는 뜻이에요. 다른 설명이 필요하면 교재나 추가 문제를 쓸 수 있지만, 내 범위와 어떤 부분을 연결하려는지 먼저 정해요.

평가 안내에 ‘성취기준’이라는 말이 나오면, 수업을 통해 무엇을 알고 무엇을 할 수 있어야 하는지를 나타낸 기준이라고 이해하면 돼요. ‘평가 요소’는 그중 실제로 확인하려는 구체적인 내용이에요. 경기도교육청의 2024년 평가계획 길라잡이도 이런 개념과 평가 설계 사례를 설명해요. 자료 속 예시를 자신의 학교의 현재 시험 범위나 채점표로 대신 사용하지는 마세요. 경기도교육청 성취평가·평가계획 개념 자료

서술형이 있는지, 풀이 과정이나 근거를 어디까지 써야 하는지, 허용된 자료나 계산 도구가 있는지도 확인해요. 모호한 것은 ‘중요한가요?’만 묻기보다 “이번 범위에 프린트 4의 뒷면까지 포함되는지 확인하고 싶어요”처럼 자료 위치를 짚어 질문하세요. 예상 출제 문제를 알아내려 하기보다 공개된 범위와 학습 요구를 정확히 이해하는 질문이에요.

2. 과목별 범위를 ‘끝났는지 볼 수 있는 일’로 나눠요

‘국어 전체’, ‘수학 두 단원’은 달력에 넣기에는 클 수 있어요. 교과서의 소단원, 수업에서 나눈 주제, 글 한 편, 관련 문제 유형처럼 확인할 수 있는 크기로 나눠 보세요. 같은 쪽수라도 시 한 편과 긴 설명문, 쉬운 확인 문제와 여러 개념이 연결된 문제는 필요한 시간이 달라요.

가상 범위표는 이렇게 만들 수 있어요. 과목명과 자료 번호는 실제 학교의 범위를 뜻하지 않아요.

  • 국어: 읽을 글 3편. 각 글의 핵심 내용·표현의 근거 확인, 학교 활동 질문에 답하기.
  • 수학: 수업에서 다룬 문제 유형 4개. 필요한 정의·조건 확인, 기본 문제와 조건이 다른 문제 풀기.
  • 영어: 본문 2개. 문장의 연결과 핵심 내용 설명, 수업에서 다룬 표현을 직접 써 보기.

이 예시에서는 3 + 4 + 2 = 9개의 공부할 대상을 나눴어요. 이 개수는 난도나 공부 시간을 같게 만든다는 뜻은 아니에요. 다른 과목이 있다면 그 과목의 범위도 함께 적어야 하고, 아홉 개만 보면 시험 전체가 끝난다고 생각하면 안 돼요.

대상마다 지금의 상태도 한 줄로 써요. ‘자료를 아직 못 받음’, ‘읽어 봤지만 설명이 막힘’, ‘기본 문제는 가능’, ‘다른 조건에서는 확인 필요’처럼요. 색깔만 칠하고 잘 안다고 판단하기보다 짧게 설명하거나 한 문제를 직접 풀어 상태를 확인하세요.

자료가 아직 없는 부분은 ‘완료’나 ‘미이해’가 아니라 ‘자료 대기’로 표시해요. 수업 진도가 나가지 않았다면 그 사실을 적고, 이미 배운 앞부분을 복습할 수 있어요. 시험 범위가 미정인 곳은 무작정 제외하지도, 반드시 나온다고 단정하지도 말고 확인할 날짜를 남겨요.

Ohio State대학교의 학습센터는 시험 주제와 자료를 모은 뒤 장·수업 내용별로 나누고, 날짜에 맞게 준비·복습 방법을 배치하는 계획을 안내해요. 종이에 직접 적어도 되고 해당 페이지의 계획 자료를 참고해도 돼요. Ohio State 여러 날에 나누는 시험 계획 안내

3. 1회독 시간만 세지 말고 직접 확인할 시간도 남겨요

회독은 정한 자료를 한 번 훑거나 읽는 한 차례를 말해요. 하지만 ‘1회독 완료’라는 표시만으로 어떤 내용을 이해하고 무엇을 할 수 있는지는 알기 어려워요. 읽은 뒤 자료를 덮고 설명하기, 직접 답 쓰기, 틀린 부분 확인하기까지 함께 계획해 보세요.

앞의 가상 범위 중 처음 확인하는 시간은 이렇게 예상했다고 해 볼게요. 실제로 재 본 시간이 아니라 계획용 추정값이에요.

  • 국어 글 3편 × 각 40분 = 120분
  • 수학 유형 4개 × 각 45분 = 180분
  • 영어 본문 2개 × 각 45분 = 90분
  • 첫 확인 합계: 120 + 180 + 90 = 390분, 즉 6시간 30분

여기에 아홉 대상을 다른 날에 각각 20분씩 다시 확인할 시간을 임시로 두면 9 × 20 = 180분이에요. 과목별로 묶어 짧게 직접 풀어 보는 확인 시간을 합계 60분으로 잡으면, 전체는 390 + 180 + 60 = 630분, 즉 10시간 30분이에요. 질문하거나 추가 자료를 읽을 시간은 아직 별도예요.

이 계산은 모든 과목을 630분이면 끝낼 수 있다는 뜻이 아니에요. 제한된 가상 범위의 작업량을 합친 예시예요. 첫 읽기만 계산했을 때보다 얼마나 더 필요한지 보려는 거예요. 실제 범위가 더 넓거나 이해가 막히면 필요한 시간이 늘어나고, 이미 설명할 수 있는 부분은 다른 방식으로 확인할 수 있어요.

달력에 남은 시간을 볼 때는 수업·통학·식사·수면·다른 약속을 먼저 제외하세요. 한 달 동안 매일 똑같은 시간이 있다고 계산하지 말고 행사, 동아리, 가족 일정처럼 달라지는 날도 표시해요. 계획이 가능한 시간보다 크면 분량·방법·순서를 다시 조정해야 해요. Cornell의 학습 일정 안내도 공부 외의 생활과 휴식을 함께 배치하도록 권해요. Cornell 공부 일정과 휴식 배분

‘남은 쪽수 ÷ 남은 날짜’만으로 하루 분량을 정하면 복습·질문·오류 수정 시간이 빠지기 쉬워요. 특히 시험 마지막 날 과목도 첫날 시험 전까지 기본 준비가 필요할 수 있어요. 첫 시험을 치른 뒤에 처음부터 시작해도 될 것이라고 미리 가정하지 마세요.

4. 1주 차, D-28~D-22에는 자료와 첫 이해를 확인해요

주가 끝날 때는 몇 시간을 했는지와 함께 무엇을 설명하거나 풀 수 있게 됐는지 봐요. 계획표의 모든 칸을 채우는 것이 시험 준비의 목적은 아니에요. 학교가 안내한 범위를 실제로 배우고, 남은 빈틈을 알아차리고, 다음 확인으로 이어 가는 데 사용하세요.

공식 자료 확인일: 2026년 10월 6일. 4주 배분, 날짜 구간, 과목·자료·시간은 직접 만든 가상 예시예요. 대학 학습센터 자료는 일반 학습 원칙을 참고했고, 경기도교육청 2024년 자료는 평가 개념 설명에만 활용했어요. 실제 시험 범위·평가 방식·현재 적용 규정은 학교의 최신 안내를 확인하세요.
