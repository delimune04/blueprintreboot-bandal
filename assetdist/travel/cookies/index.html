2026년 10월 8일 업데이트

여행 계획을 기억하는 방식

BANDAL 여행 계획 코드는 프로젝트, 단일 일정, 삭제 후 복구용 기록과 수정한 환율을 브라우저의 로컬 저장소에 보관합니다. 이것은 사용자의 여행을 기억하기 위한 기기 내 저장이며, 자체 광고·방문 분석 쿠키를 생성하는 기능은 넣지 않았습니다.

새로고침하면 시작 선택 화면으로 돌아가지만 저장한 여행은 유지됩니다. 다른 기기·다른 브라우저 또는 다른 도메인의 저장소와 자동으로 합쳐지지 않습니다.

외부 서비스

호스팅·지도·외부 항공 검색·판매처에서는 각 서비스의 운영에 필요한 접속 정보나 쿠키를 처리할 수 있습니다. OpenStreetMap 지도는 일정 화면에 들어갈 때 공개 장소 주변 타일을 요청합니다. 외부 항공 검색은 해당 화면을 직접 열 때 제공자의 정책이 적용됩니다.

이 페이지의 항공 검색 열기를 누르거나 별도 항공 페이지를 열 때 Travelpayouts 콘텐츠가 실행됩니다. 별도 항공 검색 서비스에는 검색 상태 저장·언어·통화 설정이나 제휴 성과 측정에 쓰이는 쿠키가 있을 수 있습니다. 해당 제공자의 안내에서 종류와 거부 방법을 확인하세요.

지우거나 제한하기

여행 앱의 안내 탭에서 기기 여행정보를 삭제할 수 있습니다. 브라우저의 사이트 데이터·쿠키 관리 기능으로 각 도메인의 저장을 별도로 관리할 수도 있어요. 저장을 차단하거나 지우면 여행 계획 복원이나 외부 검색의 일부 기능이 동작하지 않을 수 있습니다.

내보낸 일정 파일은 기기에서 별도로 지워야 합니다. 공용 기기에서는 여행 사용을 마친 뒤 저장 내용을 확인해 주세요.
