항공권 검색

아래 검색창에서 실제 항공권을 비교하거나, 여행 날짜를 가져온 KAYAK·Skyscanner 연결을 이용하세요.

이곳에서 항공권 가격을 비교하세요

PC에서는 검색창과 결과를 이 안에서 볼 수 있어요. 휴대폰에서는 별도 항공 검색창을 엽니다. 최종 예약·결제는 선택한 외부 판매처에서 진행해요.

해당 항공 검색을 통한 예약에 대해 수수료를 지급받습니다.

열기를 누르면 Travelpayouts가 검색 조건과 IP·기기·이용 정보 및 쿠키·제휴 추적 정보를 처리합니다. 저장한 여행 프로젝트는 자동 전달하지 않아요. 출발지가 IP로 추정될 수 있으니 공항·연도·날짜·인원·수하물을 검색창에서 다시 확인해 주세요.

출발 전 공식 정보로 운영시간, 예약, 환불 규정을 확인해 주세요.

동선은 이렇게 만들어요

필수 장소를 먼저 넣고 도시·거리·체류시간을 기준으로 날짜에 나눠요. 가까운 순서로 연결한 뒤 경로를 개선합니다. 수학적인 최적 경로를 보장하지 않아요.

검증된 구간에는 노선과 승하차역·요금을 표시하고, 그 밖의 이동은 직선거리 기반 추정으로 구분합니다. 실제 배차·혼잡·영업시간은 반영하지 않습니다. 알려진 휴관 규칙은 경고하지만 예외 운영을 보장하지 않아요.

무엇이 저장되나요?

날짜, 선택한 장소, 직접 입력한 숙소와 수정 일정은 이 브라우저의 로컬 저장소에만 저장됩니다. 다른 기기와 자동으로 동기화되지 않아요.

프로젝트에는 도시별 일정과 직접 표시한 예약 상태도 이 브라우저에 저장됩니다. 삭제한 프로젝트는 목록에서 복구할 수 있어요.

일정 생성에는 AI 모델을 사용하지 않습니다. 항공 검색은 별도 외부 서비스이며 예약 상태는 자동 동기화되지 않습니다. 지원 지역은 오사카·교토·로마·도쿄·파리·런던·서울이며, 직접 입력한 장소는 위치를 확인해야 정확히 계산할 수 있어요.

나만의 여행은 이 기기에

여행 입력과 일정 계산은 브라우저 안에서 이뤄져요. 일정 화면에서는 공개 명소·공식 거점 주변의 OpenStreetMap 지도를 자동으로 불러오며, 표시 지역·확대 수준과 IP·브라우저 정보가 제공자에게 전달됩니다. 직접 입력한 위치는 ‘직접 입력 위치도 표시’를 선택해야 지도에 포함됩니다. GPS를 사용하지 않으며 숙소명과 여행 날짜를 지도 제공자에게 보내지는 않습니다.

개인정보 안내 · 쿠키·기기 저장 · 서비스 이용 안내

이 브라우저에 자동 저장되므로 공용 기기에서는 안내 탭의 ‘이 기기의 모든 여행정보 삭제’를 이용해 주세요. 프로젝트의 일반 삭제는 복구 가능한 목록에 남습니다. 내보낸 파일에도 입력한 여행 정보가 담겨요.

항공 검색 위젯은 별도 열기 버튼을 누른 뒤 외부 Travelpayouts 콘텐츠를 불러옵니다. 위젯에서 입력한 검색 조건과 접속·기기·이용 정보는 제공자의 개인정보·쿠키 정책에 따라 처리됩니다. 위젯은 저장 여행정보에 접근하지 못하도록 별도 격리 화면에서 실행합니다.

지도·공식 사이트 링크를 직접 누르면 해당 사이트가 새 탭으로 열리고, 지도 검색어에 선택한 장소명이 전달됩니다.
