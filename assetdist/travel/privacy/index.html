여행 계획은 이 브라우저에 저장해요

여행 날짜·도시·방문 순서·취향·숙소 이름·직접 입력한 위치·인원·예산·환율 수정값·수동 예약 상태는 이 브라우저의 로컬 저장소에 보관됩니다. BANDAL 여행 계획 코드에는 이 내용을 서버로 올리거나 다른 기기로 동기화하는 기능이 없습니다. 프로젝트 복제·삭제·복구와 일정 계산도 브라우저 안에서 처리합니다.

신용카드 번호, 여권 정보나 결제용 비밀번호를 입력받는 기능은 없어요. ‘예약 완료’ 표시는 실제 판매처 확인 결과가 아닌 사용자가 직접 남긴 기록입니다.

지도가 표시될 때

첫 시작 화면에서는 지도를 요청하지 않습니다. 여행 일정에 들어가면 공개 명소·식당·공식 거점 주변의 OpenStreetMap 지도 이미지를 불러옵니다. 지도 제공자는 표시 지역·확대 수준과 IP·브라우저 정보를 처리할 수 있습니다. 숙소 이름·여행 날짜는 지도 이미지 요청에 넣지 않습니다.

직접 입력한 좌표는 ‘직접 입력 위치도 표시’를 선택한 경우에만 일별 지도에 포함돼요. 전체 여행 지도에는 공개 자료의 장소만 사용합니다. 여행 계획 기능은 기기의 GPS·현재 위치 권한을 요청하지 않습니다.

지도·예약·항공 검색을 열 때

Google Maps 링크를 누르면 선택한 장소명 또는 출발·도착 좌표가 링크에 포함됩니다. 항공권 검색 링크에는 직접 정한 출발·도착 공항과 날짜가 포함될 수 있어요. 공식 티켓·식당·예약 사이트에서는 해당 운영자의 정책이 적용됩니다. 외부 판매처에서의 예약·결제 정보는 여행 계획의 수동 체크와 자동으로 연결되지 않습니다.

Travelpayouts 항공 검색은 외부 서비스이며 검색 조건, IP·기기·이용 정보 및 쿠키·제휴 추적 정보가 해당 제공자에 의해 처리될 수 있습니다. 별도 항공 검색 화면에 입력하는 내용과 그 화면의 저장 정보는 공급자 정책을 확인해 주세요. 저장한 여행 프로젝트를 외부 항공 검색으로 자동 전달하지 않습니다. 항공 검색 열기를 눌렀을 때만 flights.bandal.app의 별도 출처 화면을 불러옵니다. 공급자는 IP에 따라 출발지를 추정할 수 있으며 기기의 GPS 권한은 요청하지 않습니다. 공항·날짜·인원은 외부 검색창에서 다시 확인해 주세요.

삭제·내보내기·공유

프로젝트를 일반 삭제하면 이 기기의 ‘삭제한 여행’에서 복구할 수 있습니다. 안내 탭의 ‘이 기기의 모든 여행정보 삭제’는 보관 중인 프로젝트·삭제한 여행·단일 일정·입력 환율을 지웁니다. 브라우저의 이 사이트 데이터 삭제로도 기기 저장 내용을 지울 수 있어요.

내보낸 파일에는 입력한 여행 내용이 포함됩니다. 이미 내려받은 파일과 외부 서비스의 쿠키·예약 내역은 앱의 여행정보 삭제로 지워지지 않아요. 공유 전에 숙소·개인 위치·예약 관련 내용을 확인하세요. 같은 웹사이트 주소를 친구에게 전달해도 내 기기의 프로젝트는 자동으로 전달되지 않습니다.
