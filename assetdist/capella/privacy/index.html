1. 적용 범위

이 방침은 TOKYO iPhone 앱의 사진 처리, 고객 문의, TestFlight 베타 테스트 및 지원·개인정보 웹페이지에서 처리되는 정보를 설명합니다.

TOKYO는 사진 촬영과 보정을 기기에서 수행합니다. 앱의 사진 처리 기능에는 회원가입, 광고, 광고 목적의 추적 또는 별도의 사용자 행동 분석 서비스가 없습니다. 다만 사용자가 이용하는 사진 동기화, 공유, 이메일 및 TestFlight에는 아래와 같이 정보 전송과 처리가 발생할 수 있습니다.

2. 사진과 앱 설정

TOKYO는 카메라 영상과 촬영한 사진, 시스템 사진 선택기에서 사용자가 고른 사진을 미리보기·촬영·보정·저장·공유에 사용합니다. 이 사진 처리 과정에서 사진을 TOKYO 운영자의 서버로 업로드하지 않습니다.

선택한 사진의 크기와 형식 등 처리에 필요한 정보를 사용하며, 원본 사진을 덮어쓰지 않고 결과 사진을 별도로 만듭니다.

필터 선택, 필터 강도, 즐겨찾기, 격자 설정은 다음 실행에도 사용할 수 있도록 기기에 저장합니다.

3. 접근 권한

  • 카메라: 사진 촬영과 실시간 미리보기에 사용합니다. 허용하지 않아도 기존 사진을 가져오거나 내장 샘플을 보정할 수 있습니다.
  • 사진 추가: 사용자가 결과를 사진 앱에 저장할 때 요청합니다.
  • 사진 가져오기: 시스템 사진 선택기에서 사용자가 고른 항목을 받습니다. 전체 사진 보관함을 읽는 권한은 요청하지 않습니다.

앱은 위치, 마이크, 연락처 접근 권한을 요청하지 않습니다. 권한은 iPhone의 설정에서 변경할 수 있습니다. 관련 권한을 거부하면 해당 기능이 제한될 수 있습니다.

4. 기기 저장, 삭제 및 공유

편집·촬영·저장·공유 과정에서 생성된 사진 파일은 앱의 임시 저장 공간에 남을 수 있습니다. 편집 화면을 닫았다고 해서 모든 임시 파일이 즉시 삭제되는 것은 아닙니다. 임시 파일은 운영체제의 정리 또는 앱 삭제에 따라 제거될 수 있습니다.

앱을 기기에서 삭제하면 앱 영역의 설정과 데이터가 제거됩니다. ‘앱 정리하기’와 기기 백업·복원은 앱 삭제와 다르게 작동할 수 있으며 운영체제 설정을 따릅니다.

사진 앱에 저장한 결과는 TOKYO를 삭제한 후에도 남습니다. 해당 사진은 사진 앱에서 직접 삭제할 수 있습니다. iCloud 사진과 기기 백업을 사용하는 경우 사진이나 앱 데이터의 동기화·보관은 사용자의 Apple 설정과 Apple 정책에 따릅니다.

사용자가 공유 메뉴에서 다른 앱이나 서비스를 선택하면 선택한 사진이 해당 대상에 전달됩니다. 이후 전송·저장·이용에는 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 이메일 문의

사용자가 support@bandal.app으로 문의하면 발신 이메일 주소, 직접 작성한 내용 및 직접 첨부한 자료를 문의 확인과 답변, 문제 해결에 사용합니다. 앱이 문의 이메일을 자동으로 발송하거나 사진을 자동으로 첨부하지는 않습니다.

문의 내용은 이메일 제공자인 Dynadot의 메일 서비스를 통해 전달·보관됩니다. 필요한 정보만 보내주시고, 비밀번호·결제정보·불필요한 민감정보는 보내지 마세요. 사진이나 스크린샷은 필요한 경우에만 선택해 첨부해 주세요.

운영자가 보관하는 문의 자료는 문의 처리와 문제 해결에 필요한 동안 보관하고, 더 이상 필요하지 않으면 삭제합니다. 법령에 따라 보관해야 하는 경우에는 해당 기간 동안 보관할 수 있습니다. 이메일 서비스 제공자의 별도 처리에 관한 사항은 Dynadot 개인정보처리방침(서비스 약관 제II부)에서 확인할 수 있습니다.

6. TestFlight 베타 테스트

TestFlight로 TOKYO를 테스트하면 Apple이 충돌 기록과 사용정보를 자동 수집하여 개발자와 공유합니다. 여기에는 앱 버전, 기기 모델, 기기 식별자, 운영체제 버전, 설치·실행 횟수 및 충돌 정보 등이 포함될 수 있습니다. 이메일로 초대받은 경우 초대에 사용된 이름과 이메일 주소도 개발자에게 표시될 수 있습니다. 공개 링크만으로 참여한 경우 이름과 이메일 주소는 기본 테스터 정보에 표시되지 않습니다.

사용자가 TestFlight로 의견이나 스크린샷을 보내면 해당 내용과 관련 기기·진단 정보가 Apple과 개발자에게 전달됩니다. 스크린샷에 개인 사진이나 개인정보가 보이는지 확인한 후 보내주세요.

운영자는 제공받은 베타 자료를 오류 분석과 앱 개선에 사용하며 제3자에게 공유하지 않습니다. 운영자가 별도로 보관하는 자료는 해당 목적에 필요한 동안 보관하고 더 이상 필요하지 않으면 삭제합니다. Apple이 보관하는 자료의 기간과 처리 방식은 Apple 정책을 따릅니다.

이 자동 수집은 TestFlight의 기능이며 베타 테스트 중에는 해당 수집만 따로 거부할 수 없습니다. 테스트를 그만두려면 TestFlight의 해당 앱 정보에서 ‘테스트 중단’을 선택할 수 있습니다. 자세한 내용은 Apple의 TestFlight 개인정보 안내를 확인해 주세요.

7. 지원·개인정보 웹페이지

이 웹페이지는 OpenAI의 Sites를 통해 제공되며 Cloudflare의 호스팅·전송 인프라를 사용합니다. 웹페이지 제공과 보안 유지를 위해 호스팅 제공자가 IP 주소, 브라우저·기기 정보, 요청 시각과 접속·전송 기록 등의 기술 정보를 처리할 수 있습니다.

운영자가 작성한 웹페이지에는 별도의 방문 분석 도구, 광고, 문의 입력 양식 또는 추적용 쿠키를 추가하지 않았습니다. 호스팅 플랫폼이 처리하는 기술 정보와 쿠키 등의 사항은 제공자의 정책과 서비스 설정을 따르며, 앱 안에서의 사진 처리와는 구분됩니다.

8. 개인정보 관련 요청

운영자가 받은 문의 또는 베타 자료의 열람·정정·삭제 등 개인정보 관련 요청은 support@bandal.app으로 보내주세요. 요청 대상과 관련 문의를 알려주시면 운영자가 처리할 수 있는 범위를 확인하여 답변합니다.

기기에만 저장된 사진과 설정은 운영자가 원격으로 열람하거나 삭제할 수 없습니다. 사진 앱, 공유 대상 서비스 또는 Apple이 관리하는 자료는 해당 서비스의 관리 기능과 개인정보 요청 절차를 이용해야 할 수 있습니다.

9. 변경 안내

정보 처리 방식이나 기능이 변경되면 이 페이지를 갱신하고 시행일을 표시합니다.
