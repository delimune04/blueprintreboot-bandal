# Review record kind filter — 2026-10-26

The read-only review navigator now combines record kind with text and review status.
A researcher can isolate failed attempts, decisions, questions, hypotheses or next
actions without hiding records from the full editor or changing the saved dossier.
Shortcuts display localized kinds so similar text remains distinguishable. Clear
filters restores all three criteria. Original row IDs and numbers remain stable.
No schema, API, permission, stored data or snapshot semantics changed.

Verification and publication evidence is recorded separately in the run receipt;
this document is not a claim that every live workflow was exercised.
