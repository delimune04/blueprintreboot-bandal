# LabVium paper reading flow

Discovery saves a Paper to the selected workspace Library, not a research page.
The save response and the discovery identity index bind stable DOI, arXiv,
OpenAlex and provider IDs to the actual Paper. Titles are never identities.
Conflicting legacy matches remain explicit and are never merged automatically.
Previously saved research pages remain under Research notes.

A metadata-only Paper stores its source bibliography, abstract and links. The
PDF state is separate. Connecting a selected PDF or explicitly fetching an
allowlisted open-access PDF attaches bytes to the same Paper ID, retaining
notes, highlights, status and project links. Reconnecting a lost original
requires its original hash; live attachments are not replaced by this command.

Reader selections saved as cited blocks become durable normalized highlights.
Floating memos use existing revision-checked idea blocks and a versioned suffix
for normalized position. The horizontal coordinate chooses a left/right margin;
the vertical coordinate is relative to the reserved memo rail. Existing saved
positions remain readable. Reader and Blocks editors hide that suffix.
Drafts remain scoped to the current account, workspace and Paper. Saving an
older snapshot does not discard edits made while the request is in flight.

Yellow post-its use actual PDF-side rails rather than a document overlay. The
local workspace width chooses side rails or a separate bottom rail on narrow
screens. Hide/show releases or restores this space while preserving the reading
anchor. Drag handles, arrow keys and left/right controls adjust a draft position;
Save commits both content and position. Multiple memo drafts remain independently
retained when switching cards, including when device storage is unavailable.

Connector arrows use exact normalized PDF selection rectangles and visible note
headers. Offscreen or unavailable source geometry never produces a guessed line.
Bottom-rail and native PDF fallback notes retain their source-page link without
a connector. A free note can explicitly link to an existing cited highlight.

Individual and all-memo hiding are independent local preferences, scoped to the
account, workspace and Paper. Hidden cards remain in the memo list and retain
their content and drafts; hiding does not delete or mutate note blocks. Corrupt
preferences remain available rather than being silently overwritten.

Paper Next Steps follows actual OpenAlex citation links or explicitly labeled
bounded topic candidates. Its trail supports backtracking; saved identities
survive remount. A project link refers to the same Library Paper and uses the
fresh project link revision. A completed Reader status starts next-paper
suggestions automatically.

Contextual AI offers selected-excerpt explanation and paper summary through
existing evidence preview and source-revision checks. Only selected sources
are sent. No model or key was connected by this update; generation stays gated
until the workspace reports a configured provider.

Validation uses disposable SQLite/IndexedDB workspaces and synthetic PDFs;
private account research is not used as test input. Real iOS touch interaction
requires device QA. The managed environment had no supported browser preview.

Search titles and explicit Read PDF / Download actions now resolve exact paper
identifiers and prepare the PDF automatically. Resolution never substitutes a
similar title. Publisher access remains explicit when no open PDF is found.
Managed downloads use verified actual PDF bytes and scoped authenticated URLs.
